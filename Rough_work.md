arrays → contiguous memory

pointers/references → how things are accessed

vector → dynamic array abstraction, but you can understand what it is hiding

stack/queue → underlying structures

trees → pointers/references + nodes

graphs → adjacency lists/matrices

memory allocation → much closer to the machine

STL → abstraction after understanding the underlying structure
